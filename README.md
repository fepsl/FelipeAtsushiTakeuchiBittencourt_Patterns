# SeuNomeCompleto_Patterns

Implementação de 3 Design Patterns (um de cada categoria) em Java:

| Categoria      | Pattern        | Pasta              |
|----------------|----------------|--------------------|
| Criacional     | Factory Method | `factory_method/`  |
| Estrutural     | Adapter        | `adapter/`         |
| Comportamental | Observer       | `observer/`        |

## Como executar

Dentro de cada pasta:

```bash
javac *.java
java Main
```
